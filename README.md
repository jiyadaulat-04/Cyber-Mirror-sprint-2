 Cyber Mirror – Sprint 2

An AI-powered cybersecurity simulation and analysis platform integrating Red AI, Blue AI, and Purple AI in a controlled environment.

Technology Stack

Frontend: Next.js, TypeScript
Backend: FastAPI, Python
Database: PostgreSQL 16
Containerization: Docker
Arena: Nginx
Monitoring: Sentry

Core Features

Security analytics dashboard.
Red AI reconnaissance analytics.
Blue AI mitigation tracking.
Purple AI security score evaluation.
Simulation management and telemetry history.
Authentication and role-based access groundwork.
Isolated Arena environment (isolation verification pending).
